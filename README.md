# offer体检（offer-checkup-skill）

> 招聘 / 公司体检技能：粘贴 BOSS直聘 / 智联招聘 / 猎聘 / 前程无忧 / 拉勾 等招聘链接（或公司名），自动爬取并交叉核验**待遇、参保人数、劳动仲裁、招聘套路、网络/抖音/高德口碑**，输出含 **1–5 星推荐指数**的单文件 HTML 报告。

适用场景：求职前快速排雷、对比多家公司、判断「这家 offer 靠不靠谱」。

## 功能

- **多站点自动爬取**：支持 BOSS / 智联 / 猎聘 / 前程无忧 / 拉勾 等招聘链接，自动调用 [browser-skill](https://github.com/Tencent/BrowserSkill) 绕过登录墙抓取职位与公司信息。
- **7 维度交叉核验**：待遇 / 参保人数 / 劳动仲裁 / 招聘套路 / 网络口碑 / 抖音口碑 / 高德口碑。
- **主体一致性校验**：自动比对「简介自称主体」与「工商登记主体」，揪出壳公司 / 规模虚报。
- **风险加权星级**：按 `references/scoring.md` 算法输出 1–5 星，并给红线建议。
- **单文件 HTML 报告**：内联 CSS，可双击打开、可归档对比。

## 安装

将仓库地址发给 AI agent 即可自动安装：

```
安装这个skill：https://github.com/mfd2033/offer-checkup-skill
```

## 前置依赖

- **[browser-skill](https://github.com/Tencent/BrowserSkill)**（腾讯开源浏览器自动化工具）：用于绕过招聘站登录墙自动爬取。未安装或无登录态时，技能会回退为 `WebFetch` 抓取 + 提示你粘贴页面文本，仍可工作。
- 联网检索能力（WebSearch / WebFetch）。

## 使用

直接对 AI agent 说触发词：

- 「帮我分析这个工作待遇怎么样？」+ 粘贴招聘链接
- 「招聘避坑」「这家 offer 靠谱吗」「公司体检」「offer体检」
- 或仅给公司名：「分析一下河南匠策信息技术有限公司」

技能会并行调研 7 个维度，产出 HTML 报告并给出星级。

## 评分方法

详见 [`references/scoring.md`](references/scoring.md)。基准 5.0 星，按社保缺失、规模虚报、主体混淆、仲裁/投诉、口碑、套路等风险逐项扣分，最低 1.0 星，四舍五入到 0.5。

| 得分 | 建议 |
|---|---|
| ≤2.0 | 高危，建议 Pass |
| 2.5–3.0 | 谨慎，重点核实风险项 |
| 3.5–4.0 | 尚可，正常推进 |
| ≥4.5 | 优质，优先推进 |
