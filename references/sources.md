# offer体检 · 维度→来源白名单（Source-Whitelist）接口

> 本文件是「各维度查哪些站、按什么顺序、用什么 URL 模板到达」的**单一事实来源**：`SKILL.md` 只引用本文件、不复制清单。改站点/模板只动本文件（并同步 bump 技能版本）。决策背景见 `references/adr/0005-source-whitelist.md`。

## 规则（强约束）

1. **有序白名单**：每维只许查本表列出的站点，按 ①→②→③ **降级顺序**尝试：主站未命中 / 登录墙 / 反爬 / 模板失效，才降到下一备站。**清单外站点一律不得作为结论来源**，不做找补。
2. **全榜未命中即降级**：备站穷尽仍拿不到可打开页面时，该维按「未获取到可核验来源」降级（对齐 ADR-0003 统一来源硬标准），**不得**换清单外站点。
3. **URL 模板直连**：各维来源页一律用 `bsk navigate` 直连本表模板，`<公司名>` 以实体确认后的**工商全称**代入，查询词后缀固定不得自创。`WebSearch` 退出来源发现路径（仅可用于实体消歧等非证据用途，搜索摘要不作数）。
4. **模板失效处理**：模板 404 / 站点改版时，允许**站内手动探索一跳**——从该站顶级页/搜索框输入同查询词进入结果页，域名仍锁该站；仍失败按规则 1 降级到下一备站。**不得**因此回退 `WebSearch` 或出清单。
5. **软维截断不变**：网络/抖音/三维的 ~3s 墙钟超时截断规则照旧，本表只消除选站与查询词的变异源，不改时延策略。
6. **台账约束**：来源台账每条 URL 的域名必须落在该维白名单内，否则不得入账、不得进报告来源行。

## 清单裁剪记录（为什么不是别的站）

- **裁判文书网（wenshu.court.gov.cn）**：无登录态基本不可达，按统一来源硬标准移出仲裁维清单（ADR-0005）。
- **启信宝**：与企查查功能重叠，删冗余。
- **贴吧**：噪声高且结果与百度搜索重叠，删。
- **前程无忧/拉勾等招聘站**：仅作链接模式输入源，不进调研白名单。

## 维护

- 模板以实测为准；站点改版先走「站内手动探索一跳」应急，随后修订本表并升技能版本。
- 新增/删除站点须同步更新 ADR-0005 的裁剪记录与本表，保持单一事实来源不漂移。
