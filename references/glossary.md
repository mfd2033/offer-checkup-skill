# offer体检 · 领域术语表（Glossary / CONTEXT）

> 本文件是 offer体检 技能的词汇表，仅记录术语定义，不含实现细节。实现变更请见 `references/adr/`。
> **同步纪律**：每个术语必须能在 `SKILL.md` 找到对应运行时段落。本表随 ADR-0001/0002 修订为「页面取工商 + 单批并行 + 早停仅裁剪报告」模型；旧「工商门 / 两波式 / 动态选维」已废弃，保留词条仅作历史对照，避免未来架构评审误提。

## 核心术语

- **体检（Checkup）**：对一份招聘信息或一家公司进行一次入职前全面评估，产出 1–5 星推荐指数与单文件 HTML 报告。
- **维度（Dimension）**：七条评估轴——待遇 / 参保人数 / 劳动仲裁 / 招聘套路 / 网络口碑 / 抖音口碑 / 高德口碑。默认全维；`--lite` 显式砍 抖音+高德（保留网络口碑），属覆盖度权衡，不影响墙钟。
- **页面取工商（Page-Extract IC）**：链接模式抓取职位页后，直接从页面文本解析工商字段（主体 / 企业类型 / 规模 / 成立 / 注册资本 / 经营状态）。**非串行门、不前置**；参保人数若页面未给，则作为并行批次中的一个调用补查（企查查/天眼查/爱企查工商年报）。BOSS/猎聘/智联职位页均自带该区块，各站字段覆盖与壳识别见 `references/extraction.md`。替代原「工商门（主门）」。
- **同消息全发（Single-Message Fan-out）**：在同一助理消息中并发发出全部所需外部调用，以最大化并行、压低总时延（墙钟 = 最慢一跳）。
- **单批并行（Single-Batch Orchestration）**：编排模式——页面取工商 + 实体确认后，余维一次性同消息 fan-out，无波次串行。替代原「两波式」。
- **硬红线（Hard Red Line）**：一类可立即判定高危的信号。命中任一条即**裁剪报告低权章节**（网络口碑 / 抖音 / 高德），但已发出的调用不撤回，故早停**不影响墙钟**、只服务于正确性与省 token。当前红线：① 工商实测参保=0 或明确不缴；② 简介主体 ≠ 工商主体 或 自然人独资微型壳；③ 仲裁 / 投诉爆量（黑猫大量投诉 + 公开仲裁集中）。
- **报告裁剪集（Report-Prune Set）**：命中红线后报告中**保留**的章节集合，固定为 **待遇 / 参保 / 仲裁 / 套路** 四章（省略网络口碑 / 抖音 / 高德 三章）。注意：这是**报告章节集，非调用集**——调用已在 fan-out 中并发发出，早停不跳调用。替代原「缩减集」。
- **动态选维（Dynamic Dimension Selection，已废弃）**：原指「依工商门信号补跑剩余维度」。ADR-0001 后工商门改为页面内联解析、余维改为默认全维同消息 fan-out，该机制不再作为运行时路径存在；现存唯一等价物为用户显式 `--lite` 选项（砍抖音+高德）。保留词条仅作历史对照。
- **来源台账（Source Ledger）**：调研阶段维护的结构化留痕清单，每条为 `{维度, 平台名, 已打开URL}`。报告各段来源行均据台账渲染，是把「不得编造 URL」与「无来源即不下结论」落成可校验数据结构的机制（ADR-0003）。
- **真访问 URL（Actually-Fetched URL）**：本次运行中经 WebFetch / browser-skill **真正抓取或打开过**的页面 URL。**所有维度一视同仁**：任何给出自信结论的维度，其来源仅接受真访问 URL（搜索摘要/未打开的返回 URL 不算数）。
- **统一来源硬标准（Uniform Source Bar）**：ADR-0003 修订后的规则，**取代原「硬维严/软维中」分档**——所有维度同一条线：要么挂本次真打开过的来源 URL，要么不得下自信结论。
- **未获取到可核验来源（No Verifiable Source）**：某维拿不到可打开的权威来源页时的降级态——**不摆“看起来有据”的分析**，徽标标注「未获取到可核验来源」、正文写明原因（无公开页/登录墙/反爬），来源行留空自动隐藏。绝不拿搜索入口链接充数。
- **主来源（Primary Source）**：报告头部那条指向**职位页**的链接，与一~七各段内联来源行并存；顶部四张信息卡不挂链接，出处归一到对应段。
