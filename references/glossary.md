# offer体检 · 领域术语表（Glossary / CONTEXT）

> 本文件是 offer体检 技能的词汇表，仅记录术语定义，不含实现细节。实现变更请见 `references/adr/`。

## 核心术语

- **体检（Checkup）**：对一份招聘信息或一家公司进行一次入职前全面评估，产出 1–5 星推荐指数与单文件 HTML 报告。
- **维度（Dimension）**：七条评估轴之一——待遇 / 参保人数 / 劳动仲裁 / 招聘套路 / 网络口碑 / 抖音口碑 / 高德口碑。默认评估全部，但可被「动态选维」裁剪。
- **工商门（Industrial-Commerce Gate / 主门）**：每次体检最先执行的「参保人数 + 主体一致性」查询（来源：企查查 / 天眼查 / 爱企查工商年报）。其结果是后续动态选维与早停的决策依据，**必跑**。
- **动态选维（Dynamic Dimension Selection）**：依据工商门返回的参保 / 规模 / 主体信号，决定补跑哪些剩余维度，而非固定全跑。
- **硬红线（Hard Red Line）**：一类可立即判定高危的信号。命中任一条即停止低权维度，仅保留最高权重维度后直接出报告。当前红线：① 工商实测参保=0 或明确不缴；② 简介主体 ≠ 工商主体 或 自然人独资微型壳；③ 仲裁 / 投诉爆量（黑猫大量投诉 + 公开仲裁集中）。
- **两波式（Two-Wave Orchestration）**：编排模式——波1 发工商门（1–2 调用），看完结果；波2 按门结果一次性并发其余所需维度（同消息全发）。
- **同消息全发（Single-Message Fan-out）**：在同一助理消息中并发发出全部所需外部调用，以最大化并行、压低总时延。
- **缩减集（Reduced Set）**：命中红线后保留的维度集合，固定为 **参保 + 仲裁 + 套路** 三项。
