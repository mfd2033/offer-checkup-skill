# offer体检 · 星级权重算法

推荐指数以 **5.0 星为基准**，按风险因子逐项扣分，最低 **1.0 星**（公司仍存续属唯一微弱加分，不因「有坑」给 0 星）。

## 评分公式

```
最终得分 = max(1.0, 5.0 - Σ扣分)  →  四舍五入到 0.5
```

## 风险因子与扣分表

| 因子 | 判定 | 扣分 |
|---|---|---|
| **社保/参保风险**（权重最高） | 工商实测参保人数=0 或明确不缴 | **-2.0** |
| | 参保人数远低于宣称规模（如宣称 100–499 人，实测 <10） | -1.0 |
| | 正常（参保与规模匹配） | 0 |
| **规模虚报** | 宣称规模与工商严重不符 | -1.0 |
| | 轻微不符 | -0.5 |
| | 一致 | 0 |
| **主体混淆/壳公司** | 简介主体 ≠ 工商主体，或自然人独资微型壳 | -1.0 |
| | 无 | 0 |
| **劳动仲裁/投诉** | 有公开劳动仲裁/集体诉讼/黑猫大量投诉 | -1.5 |
| | 零星个案 | -0.5 |
| | 无 | 0 |
| **网络口碑** | 职友集/看准 ≤3.0/5 或多条一致负面 | -1.0 |
| | 3.0–4.0 或褒贬不一 | -0.5 |
| | ≥4.0 且正面为主 | 0 |
| **招聘套路** | title 虚高 + 薪资偏低 / 软文刷屏 / 地址混乱 等，每项 -0.5，**封顶 -1.5** | -0.5 ~ -1.5 |
| **抖音/高德负面** | 有集中负面爆料 | -0.5 |
| | 无 / 未获取到 | 0 |

## 实操建议

- **≤2.0 星**：高危，明确建议 Pass，附「面试必须确认的红线」（签约主体、社保缴纳方与基数、书面 offer）。
- **2.5–3.0 星**：谨慎，可接触但需重点核实风险项。
- **3.5–4.0 星**：尚可，正常流程推进。
- **≥4.5 星**：优质，优先推进。

## 样例：匠策科技（技术总监岗）

| 因子 | 判定 | 扣分 |
|---|---|---|
| 社保 | 工商实测参保 0 人 | -2.0 |
| 规模 | 标 100–499 人 vs 实测 0 人 | -1.0 |
| 主体 | 简介「匠库」vs 工商「匠策」 | -1.0 |
| 仲裁 | 未检索到公开仲裁/投诉 | 0 |
| 口碑 | 职友集 2.6/5 | -1.0 |
| 套路 | title 虚高+薪资偏低+地址混乱（封顶） | -1.5 |
| 抖音/高德 | 无有效口碑 | 0 |

`5.0 - 5.5 = -0.5 → 触底 1.0` ⇒ **★☆☆☆☆（1.0/5，高危，与人工评 2★ 同属不可选区间）**

## 样例：京东集团（体检销售团队负责人岗）

| 因子 | 判定 | 扣分 |
|---|---|---|
| 社保 | 参保 1.0–1.6 万人（2022/2023 年报），与宣称 10000+ 人匹配 | 0 |
| 规模 | 大型（2024 划型），BOSS 标注一致 | 0 |
| 主体 | 招聘「京东集团」= 北京京东世纪贸易（核心运营主体） | 0 |
| 仲裁 | 宿迁人社局：年立案 <10 件、发生率 <0.3%（政府合规示范） | 0 |
| 口碑 | 福利/平台正评 vs 加班/狼性负评，褒贬不一 | -0.5 |
| 套路 | 多平台真实同发，无 | 0 |
| 抖音/高德 | 无集中负面 | 0 |

`5.0 - 0.5 = 4.5` ⇒ **★★★★½（4.5/5，优质）**
