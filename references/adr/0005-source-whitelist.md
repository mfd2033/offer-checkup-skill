# ADR-0005 · 维度→来源站点白名单固定化：有序降级、URL 模板含固定查询词直连

- **状态**：采纳（Accepted）
- **日期**：2026-09-26
- **决策人**：用户 + agent（grill-with-docs-pro 流程）
- **关联**：ADR-0003（统一来源硬标准 / 来源台账）；ADR-0004（bsk 硬依赖、禁 WebFetch）；`SKILL.md`「前置依赖」「并行调研」「来源台账」「注意事项」；`references/sources.md`（本决策的单一事实来源文件）
- **关联术语**：见 `references/glossary.md`（来源白名单 / URL 模板直连）

## 背景（Context）

改版前 `SKILL.md` 维度表的「主要数据源」列每维都是**并列多选**（参保=企查查/天眼查/爱企查，仲裁=裁判文书网/企查查司法/启信宝/黑猫投诉，套路=职友集/脉脉/知乎，口碑=百度/微博/贴吧/职友集评分），且到达方式允许 agent 先用 `WebSearch` 自由发现候选 URL 再 `bsk` 打开。两个自由点叠加导致：**不同 agent 跑同一技能，查的站不同、同站查询词也不同，结论与来源行不可复现**。用户要求把各维度使用的网站固定下来，消除跨 agent 方差。

起草时纳入的实测事实：京东样本（2026-09-17）中企查查企业详情页经 bsk 真打开并拿到年报参保与司法区块；裁判文书网无登录态基本不可达；脉脉登录态依赖（bsk 走用户已登录浏览器时可用）；`references/scoring.md` 网络口碑扣分阈值直接读职友集评分（评分锚点，非可选项）；软维查询词既有口径见 `.scratch/softdim_queries.txt`。

## 决策（Decision）

1. **有序白名单（约束强度）**：每维固定一个可查站点有序集（主站→备站依次降级）。只许查清单内站点；主站未命中/登录墙/反爬/模板失效才降下一备站；**清单外站点一律不得作为结论来源**，全榜未命中即该维按「未获取到可核验来源」降级（复用 ADR-0003 既有降级态，不发明新态）。
2. **URL 模板直连（到达方式）**：各维来源页一律 `bsk navigate` 直连固定模板（域名+路径+**固定查询词后缀**均定死，`<公司名>` 代入实体确认后的工商全称），**`WebSearch` 退出来源发现路径**（仅保留实体消歧等非证据用途）。把域名、查询词两个变异源一次杀干净。
3. **七维清单**：待遇=职位页（输入链接）→职友集薪资；参保=企查查→爱企查→天眼查；仲裁=企查查司法→黑猫投诉；套路=职友集→知乎→脉脉；网络口碑=职友集评分→百度→微博；抖音=抖音搜索（单站）；高德=高德地图（单站）。清单裁剪：**删裁判文书网**（不可达站不配进白名单）、**删启信宝**（与企查查重叠）、**删贴吧**（噪声高且与百度重叠）；脉脉按登录态依赖降为末位备胎而非删除。明细与模板见 `references/sources.md`。
4. **模板失效处理**：允许**站内手动探索一跳**——从该站首页/搜索框输入同查询词进结果页，域名仍锁该站；仍失败降下一备站。不开 `WebSearch`+域名过滤的回退口子（被否决：重新引入随机源）。
5. **落点**：新建 `references/sources.md` 作单一事实来源（对齐 `extraction.md` 的 seam 模式）；`SKILL.md` 维度表删除「主要数据源」列只留引用，`extraction.md`/`glossary.md` 中散落的站点罗列改为指向 sources.md。
6. **不新增测试**（被否决：离线结构测试 / 联网可达性测试）：单一事实源+引用不复制已把漂移风险压到结构性很低；模板可达性靠运行时 bsk 真打开自然验证，联网测试会被反爬误报。
7. **时延策略不变**：单批并行、软维 ~3s 超时截断、硬红线早停裁剪照旧；本决策只固定「查哪、怎么到」，不改「何时砍」。

## 后果（Consequences）

- **正面**：跨 agent 选站/查询词方差归零，报告来源可复现、可对比；模板直连省掉 WebSearch 发现一跳（压时延顺带收益）；登录墙站排序显式化，降级路径确定。
- **成本 / 负面**：站点改版即模板腐化，需人工维护 `sources.md`；白名单外出现更优信源时不会自动利用，须走「改清单→升版本」流程；清单可能整体略降覆盖多样性（如口碑维不再随机命中贴吧/小红书等长尾站）。
- **既有规则衔接**：ADR-0004 中「`WebSearch` 仅用于发现/定位候选 URL」的表述随本决策收紧为「退出来源发现路径」；ADR-0003 统一来源硬标准不变，另叠加「入账 URL 域名须在白名单内」一条。
