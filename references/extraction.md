# offer体检 · 页面解析（Page-Extract）接口

> 本文件是「页面取工商」这一 seam 的单一 interface：SKILL.md 引用本文件，`tests/fixtures/job-pages/README.md` 与 `tests/test_extract_工商.py` 是其权威数据来源与回归锚点。**改 fixture 时同步更新下表**，避免 SKILL.md 与 tests 漂移。

## 职责

链接模式抓取职位页后，从页面文本解析工商字段，供主体一致性比对与硬红线早停判定使用。

- **非串行门、不前置**：解析在抓取阶段内联完成，不单独发起一轮串行调用。
- **参保人数若页面未给**：交由并行批次补查（企查查/天眼查/爱企查工商年报），不阻塞其余维度。

## 各站可解析字段（实测结论，6 份 fixture）

| 站点 | 可直接解析的工商字段 | 缺失（需并行补查） |
|---|---|---|
| BOSS | 成立日期·经营状态·企业类型·法定代表人 | 注册资本·公司规模 |
| 猎聘 | 注册资本 + 公司规模(500-999人等) | 企业类型·成立·经营状态·法定代表人（但**个人独资/自然人独资**会缀在公司名后，可直接触发早停） |
| 智联 | 企业名称·企业类型·法人代表·经营状态·成立时间·注册资本(分公司常--) | 公司规模 |

## 壳公司识别

- **BOSS / 智联**：读「企业类型」字段是否含 `自然人独资` / `微型`。
- **猎聘**：职位页把「个人独资/自然人独资」直接缀在公司名后（如「河南牦之鲜商贸行(个人独资)」），公司名后缀即触发早停，无需结构化企业类型字段。
- 早停分支由 `tests/test_extract_工商.py` 的 A 段断言覆盖（盛启新程、河南牦之鲜 两个壳样本）。

## 参保人数（P0-2 已知限制）

所有招聘职位页（含 6 份 fixture）均不含「参保人数」（参保在工商年报/国家公示系统，不在 JD 页）。故「页面已含参保 → 删工商调用」路径在真实 JD 输入下基本不可触发；本技能默认并行补查参保，不依赖该分支。

## 字段映射（智联）

`成立时间 → 成立日期`、`法人代表 → 法定代表人`；注册资本对分公司常显示 `--`。
